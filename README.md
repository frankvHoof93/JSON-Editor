# JSON Editor
**Version 1.1**  
Created by **frank@vanhoof.dev**

JSON Editor is a lightweight and intuitive Unity Editor extension that lets you **quickly view and edit JSON files directly inside the Unity Editor**.  
It's ideal for configuration data, gameplay values, localization files, test data, and any workflow involving structured JSON.

The tool appears as a dedicated EditorWindow under:
Tools -> JSON Editor

---

## ✨ Features

- 📂 **Open JSON files** from anywhere on your system
- 🌳 **Tree-based structure view** for easy navigation
- 📝 **Edit keys, values, objects, and arrays** directly
- ➕ **Add new fields and elements** with a single click
- ❌ **Delete nodes** safely with built-in controls
- 🔄 **Auto-formatting & clean output**
- 💾 **Save changes back to disk**  

---

## 🚀 Getting Started

### 1. Install the Package  
Install via UPM or import directly into your project.  
This package requires:
com.unity.nuget.newtonsoft-json

(Unity should fetch it automatically.)

---

### 2. Open the Editor  
In the Unity menu bar:
Tools -> JSON Editor
An EditorWindow will appear for viewing and editing JSON content.

---

### 3. Load a JSON File  
Click **Open JSON File**, browse to a `.json` file, and the structured tree will be displayed.

You can:

- expand/collapse objects and arrays  
- edit values in place  
- add new entries  
- delete existing ones  

---

### 4. Save  
Click **Save** to write changes back to the file.  
The output is formatted for readability and preserves valid JSON.

---
